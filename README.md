# Kumon bowser 
> Apenas um navegador feito para ser Rápido e Costumizavel para todos.

*Esse projeto é mais para estudos e passa tempo tbm :)*

### Tecnologias usadas no Browser:

- vue, tailwind, axios e fastify;
- bun/nodejs;
- sql/postgres, txt, toml, json, yml, env e md;
- typescript, javascript, rust e python;
- canvas e engine proprio;
- Buscador open source e Buscador proprio;
- ffmpeg;
- html, css;

### Motor de renderização:

Usamos um motor de renderização proprio construido em Rust e Typescript.

### Buscadores:

Usamos dois Buscadores no browser, um é nosso e outro é open source que usamos neste projeto.
