# Kumon browser;

## O que é Kumon?

**Kumon Browser** é um Navegador independente construido sobre Tecnologias Modernas e Seguras garantindo uma navegação mais Rápida e Segura com o Kumon Browser.

## Por que o Kumon Browser?

O **Kumon Browser** oferece tudo que Voce precisa para navegar pela Internet com Segurança avançada, Design personalizavel e limpo, Criptografia de ponte em ponte no Banco de dados local do Navegador, Plugins que vão ajudar no dia a dia, uma Internet limpa de anúncios e patrocinados nas busca pela informação ou diversão.

## As tecnologias atuais são suportadas pelo Kumon?

Sim, O **Kumon** suporta as diversas tecnologias da Web moderno garantindo que tudo funcione como esperado pelo Usuario.

## Proteção de dados o Kumon possui?

Sim, O **Kumon** possui um sistema de Proteção de dados super avançado que protege contra Cookies, Anúncios, Scripts.
